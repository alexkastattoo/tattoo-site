# Alex Kas Tattoo Design Studio

## Размещение

1. Распакуйте ZIP и загрузите `index.html` и `api.php` в одну папку сайта, например `public_html/tattoo-studio/`.
2. В панели хостинга задайте переменные окружения для PHP:
   - `OPENAI_API_KEY` — ключ проекта OpenAI с доступом к Images API и настроенной оплатой.
   - `STUDIO_ACCESS_CODE` — отдельный секрет из 64 строчных шестнадцатеричных символов. Сгенерируйте его локально командой `openssl rand -hex 32`.
3. Откройте `https://ваш-домен/tattoo-studio/index.html`. Если хостинг настроен отдавать `index.html` по умолчанию, можно открыть адрес папки.
4. Введите секрет из `STUDIO_ACCESS_CODE` в поле **Studio access code** и запустите генерацию. Для смены кода обновите переменную на сервере и введите новый код в браузере.

Храните оба секрета в настройках сервера, доступных процессу PHP. Уточните у хостера, как передать переменные в PHP-FPM или другой обработчик PHP. Ключ OpenAI не вводится в интерфейсе. Код студии передаётся в заголовке HTTPS-запроса к API и не записывается приложением в историю браузера. Доступ к коду даёт возможность расходовать лимит OpenAI.

## Требования к хостингу

- HTTPS, исполнение PHP 8.0+ для `api.php`, расширения cURL и fileinfo.
- Исходящий HTTPS к `api.openai.com`, доступ проекта к модели `gpt-image-1.5`.
- Для пяти референсов до 10 МиБ каждый настройте `upload_max_filesize=10M`, `post_max_size=55M` или больше, `max_file_uploads` не ниже 5 и соответствующий лимит тела запроса на веб-сервере.
- Таймаут PHP, веб-сервера и прокси должен позволять дождаться ответа. Сам запрос к OpenAI ограничен 180 секундами.
- На статическом хостинге открывается интерфейс. Генерация и редактирование требуют отдельного сервера с PHP или адаптации API под серверные функции выбранной платформы. Этот ZIP рассчитан на размещение HTML и API по одному адресу сайта.

## Быстрая проверка

Откройте `api.php` в браузере. Должен прийти JSON с сообщением `POST required` и статусом 405. Затем отправьте запрос из интерфейса с неверным кодом. При настроенном коде сервера должен прийти статус 403. С правильным кодом проверьте генерацию по тексту, по референсу и редактирование результата.

Референсы передаются в OpenAI для обработки. История хранится в текущем браузере и ограничена его доступным хранилищем. Скачивайте готовые дизайны, которые хотите сохранить.
